# Courier Control Design V1

`courier-control-v1-reference.png` — официальная визуальная опора утверждённого Design V1.

При продолжении frontend-разработки необходимо смотреть одновременно:
- `/DESIGN_SPEC.md` — авторитетное описание поведения, адаптивности, ролей и уточнений;
- `/design/v1/courier-control-v1-reference.png` — визуальный характер, иерархия и композиционная цель.

PNG не является требованием буквального pixel-perfect копирования артефактов генерации. Если визуальная картинка и поведенческое правило расходятся, `DESIGN_SPEC.md` имеет приоритет. Новое визуальное направление без отдельного решения не вводить.
