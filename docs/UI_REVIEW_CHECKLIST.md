# UI review checklist

Before a UI change is called stable:

- [ ] 320 px: no page-level horizontal overflow
- [ ] 375 px: no overlap or clipped controls
- [ ] 390/393 px: iPhone layout reviewed
- [ ] 430 px: large-phone layout reviewed
- [ ] 768 px: tablet layout reviewed
- [ ] 1440 px: desktop layout reviewed
- [ ] Inputs have complete borders and readable centered content
- [ ] Buttons do not cover form content
- [ ] Long Russian labels do not break cards unexpectedly
- [ ] Horizontal card rows swipe without visible system scrollbar
- [ ] Login, statistics, courier form and route editor smoke-tested
- [ ] Real iPhone verification completed
- [ ] Stable checkpoint created after deployment approval
